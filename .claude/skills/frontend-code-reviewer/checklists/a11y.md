# A11y Checklist (WCAG-oriented)

## 语义化与结构
- 用语义化 HTML（button/a/input/label 等），避免 div 伪按钮
- 标题层级合理（h1-h6）
- 图像有合适 alt（装饰图可空 alt）

## 键盘与焦点
- 全流程可键盘操作（Tab/Shift+Tab/Enter/Space/Esc）
- 焦点可见（focus ring 不被移除）
- 弹窗/抽屉：focus trap、关闭后 focus 返回触发源
- 动态内容更新：必要时用 aria-live

## 表单
- label 与输入关联（htmlFor/id）
- 错误信息可被读屏获知（aria-describedby / role=alert）
- 必填字段明确（不要只靠颜色）

## 视觉与对比度
- 文本对比度达标
- 不仅靠颜色传达信息

## ARIA（谨慎使用）
- 仅在语义化 HTML 不足时再加 ARIA
- role 与属性匹配且不冲突
