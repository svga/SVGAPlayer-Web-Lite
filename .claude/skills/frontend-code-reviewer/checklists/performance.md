# Performance Checklist

## 以用户体验指标为锚
- 关注 Core Web Vitals：LCP（加载体验）、INP（交互响应）、CLS（视觉稳定）
- 如果这是关键页面/首屏：优先检查首屏资源、关键渲染路径、布局抖动来源

## React/SPA 常见性能坑
- 避免“为了优化而优化”：先去掉不必要的 state/effect 链式更新
- 避免不必要的 Effects 触发重复渲染；修复渲染逻辑问题优先于到处加 memo
- 热路径：列表渲染、复杂计算、频繁 state 更新

## 体积与加载策略
- 大依赖是否必须？是否可按需加载？
- 图片：尺寸、格式、懒加载、占位以避免 CLS
- 字体：预加载策略、FOIT/FOUT 风险
- 代码分割：路由级/组件级懒加载是否合理

## 性能预算（防回归）
- 是否有 bundle size / Lighthouse / 指标阈值等预算？
- 变更是否明显突破预算或需要调整阈值/拆分？
