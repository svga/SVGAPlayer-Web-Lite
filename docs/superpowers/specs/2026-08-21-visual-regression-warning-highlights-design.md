# SVGA 可视化测试退化与警告高亮设计

## 目标

让维护者在单素材、热播放和全量对比结果中快速发现性能退化与运行警告，同时保持现有比较算法、指标文字和报告结构不变。

## 展示规则

- 当指标结论为 `regression` 时，在指标行设置明确的状态属性。
- 桌面端使用浅红背景、左侧红色强调线和醒目的“↓ 退化”结论；移动端沿用同一整卡高亮，不依赖颜色表达状态。
- 所有警告消息使用统一的黄色警示容器，增加可见图标、完整边框和更清晰的文字对比度。
- 正确性未通过、数据受限、改善、波动带内和观察值继续使用现有中性展示，不误标为性能退化。
- 全量结果中，如果某个素材的主要结论为退化，则高亮该素材行；正确性失败继续使用原有错误状态样式。

## 实现边界

- 复用 `MetricComparison.outcome`，不通过匹配中文文本判断状态。
- 只修改可视化测试页面和浏览器测试，不改变 `Parser`、`Player`、`DB`、统计公式或 JSON 报告。
- 保持现有颜色体系、字体和布局，不引入依赖、动画或远程资源。

## 验证

- 浏览器测试构造确定性的退化和警告结果，先验证缺少高亮时失败，再验证实现后通过。
- 检查冷启动与热播放指标行的状态属性、退化文字和警告语义。
- 在桌面和 390×844 移动视口确认整行/整卡高亮、警告可读性和无横向溢出。
- 运行相关单元测试、浏览器测试、代码检查和差异格式检查。
