# SVGAPlayer-Web-Lite v2.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the local `dev` branch as v2.2.0 with public progress and frame-seeking APIs, an explicit OffscreenCanvas fallback, issue regressions, documentation, and release metadata.

**Architecture:** Extend the existing Player state machine rather than adding a second playback controller. Seeking stores the elapsed timeline position already used by pause/resume; the OffscreenCanvas option reuses the existing surface factory and cache cleanup. Parser and package behavior remain rooted in the current request-ID and package-exports architecture.

**Tech Stack:** TypeScript 7, Vitest 4, Playwright 1.62, Rollup 4, npm 12, Node.js 24.

## Global Constraints

- Work on the current clean `dev` branch.
- Keep `mount()` free of implicit first-frame rendering.
- Keep the default OffscreenCanvas preference unchanged.
- Do not add audio playback, content modes, deep imports, or legacy compatibility layers.
- Do not push, publish, tag, deploy, merge remote PRs, or update remote issues.
