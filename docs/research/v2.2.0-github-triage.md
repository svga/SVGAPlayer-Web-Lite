# SVGAPlayer-Web-Lite v2.2.0 GitHub Triage

Date: 2026-08-20

Baseline: `dev@e1b9a4159774e6185479eda120e57f458ddef85c`

This record captures the open issue and pull request review used to define the
v2.2.0 scope. GitHub issue text, comments, pull request metadata, and diffs were
read from the repository's public GitHub pages and REST API. No remote issue,
pull request, branch, release, or package state was changed.

## Local evidence

- The baseline passed 232 unit tests, 76 browser tests with 2 expected skips,
  coverage thresholds, and packed-package verification.
- An extensionless HTTP route serving `11.svga` parsed in Chromium, Firefox,
  and WebKit.
- A packed copy of the current package built successfully in a Rollup consumer
  and a Vite 4.4.5 production consumer.
- Twenty create/mount/start/pause/destroy cycles in Chromium and WebKit closed
  all 60 player-owned `ImageBitmap` objects in each browser.
- `onProcess` currently receives no argument, and `mount()` sizes but does not
  draw the canvas. Both behaviors were reproduced against the built UMD bundle.

These browser checks are desktop automation. They are not evidence of iOS 16.4
or iOS 17 device behavior.

## Release boundary

- v2.2.0 continues to support SVGA 2.x animation rendering and intentionally
  ignores audio playback.
- The default path still prefers a usable OffscreenCanvas. The new switch is a
  caller-controlled fallback, not a new default or a device certification.
- The implementation will be committed locally on `dev`. It will not be pushed,
  tagged, published, deployed, or used to change GitHub issue/PR state.

## Implementation outcome

- Player progress, progress callbacks, explicit frame seeking, and the
  OffscreenCanvas disable control were implemented in local commit `ac069b6`.
- Successful HTTP downloads no longer abort their completed request signal;
  the focused parser correction is local commit `7d68ba4`.
- The browser and packed-package regressions are local commit `114c682`.
- Final verification passed 243 unit tests and all coverage gates: 96.41%
  statements, 93.58% branches, 95.67% functions, and 98.36% lines.
- Chromium, Firefox, and WebKit passed 88 browser tests; 2 Chromium-only sweep
  duplicates remained intentionally skipped in Firefox and WebKit.
- The real packed package passed CommonJS, ESM, UMD, TypeScript, Rollup, Vite
  4.4.5 production build, deterministic build, size, syntax, file-list, and
  rejected-deep-import checks.
- No iOS device claim was made, and no remote or published state was changed.
