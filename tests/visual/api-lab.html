口径说明

这些结论如何产生

共享 API在本地与基线各执行一次，行为结果（观测值与检查项）必须一致；仅在 2.2.0 存在的 API 只运行本地，并标记“仅 2.2.0”，不计失败。

计时使用 performance.now()；3 轮以上会先丢弃一个预热样本，再以中位数、MAD 和 5% / 2×MAD 带宽判断改善或回退。基线与本地 版本相同时，计时结果强制落在波动带内；低于 1 ms 的中位数按计时分辨率噪声处理。

隔离：所有用例在独立 iframe 中顺序执行，每个用例使用新的 Canvas、Parser、Player 和唯一命名的 IndexedDB；用例结束会逆序清理。

边界：结果只代表当前机器与浏览器，不是真机、发布或持续集成性能门槛。
